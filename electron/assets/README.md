# ملف نائب — استبدله بأيقونتك الحقيقية

هذا المجلد يجب أن يحتوي على ملف **`icon.ico`** حجم 256×256 (أو 512×512).

## كيفية إنشاء الأيقونة

1. صمّم لوغو التطبيق بصيغة PNG 512×512
2. حوّله إلى `.ico` باستخدام:
   - https://convertico.com/  (أونلاين مجاني)
   - أو `png2ico` command-line
   - أو Photoshop/GIMP (تصدير كـ .ico مع تضمين 16/32/48/256)

3. احفظ الملف في هذا المسار بالضبط:
   ```
   electron/assets/icon.ico
   ```

بدون هذا الملف، `electron-builder` سيستخدم أيقونة Electron الافتراضية.
